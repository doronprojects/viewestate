הסרטון הקולנועי בראש דף הבית. לאיכות הגבוהה ביותר — העלה ל-CDN וידאו והדבק כאן את הקישור (HLS .m3u8 או mp4).
למה CDN לוידאו? וידאו באיכות 4K הוא קובץ כבד. שירות וידאו ייעודי (Cloudflare Stream / Bunny Stream) מאחסן את הוידאו, מייצר ממנו אוטומטית כמה רמות איכות, ומגיש לכל צופה את האיכות הכי גבוהה שהמכשיר והאינטרנט שלו תומכים בה — בלי להכביד על טעינת האתר. אחרי שתעלה וידאו לשירות כזה, הדבק כאן את קישור ה-HLS.
חיבור האתר לפרסום אוטומטי
חיבור חד-פעמי. אחרי זה כל "פרסם לאתר" מעלה את השינויים לבד.
איך יוצרים טוקן (פעם אחת):
  1. היכנס ל-GitHub ← Settings ← Developer settings ← Fine-grained tokens ← Generate new token.
  2. תן שם, בחר את המאגר viewestate, ותחת Permissions ← Repository ← Contents = Read and write.
  3. Generate, העתק את הטוקן (מתחיל ב-github_pat_), הדבק כאן ולחץ "שמור חיבור".
מדריך שימוש
כל מה שצריך לדעת כדי לעדכן את האתר. הזרימה תמיד אותה אחת: עורכים → שומרים → מפרסמים.
1
כניסה

נכנסים ל-viewestate.co.il/admin.html ומקלידים את קוד הכניסה (viewestate2026).

2
חיבור לאתר — פעם אחת בלבד

זה מה שמאפשר לשינויים לעלות לאתר החי לבד. בלשונית "חיבור ופרסום":

  1. ב-GitHub: Settings ← Developer settings ← Fine-grained tokens ← Generate new token.
  2. בוחרים את המאגר viewestate, ותחת Permissions ← Repository ← Contents = Read and write.
  3. מעתיקים את הטוקן (מתחיל ב-github_pat_), מדביקים, ולוחצים "שמור חיבור" ← "בדוק חיבור".
  4. מופיע "✓ מחובר" — סיימת. הטוקן נשמר רק בדפדפן שלך.
3
להוסיף או לערוך נכס

בלשונית "נכסים" ← "+ נכס חדש" (או "ערוך" על נכס קיים). ממלאים את השדות ולוחצים "שמור נכס".

4
תמונות וּוידאו של נכס

בתוך טופס הנכס:

  • גלריה: "בחר קובץ" מתחת לתיבה ← בוחרים תמונה אחת או כמה ← הן עולות לבד והקישור נכנס. התמונה הראשונה = הראשית בכרטיס.
  • poster: מעלים קובץ או מדביקים קישור.
  • וידאו: מדביקים קישור (mp4 / CDN), או משאירים ריק לתמונה בלבד.
5
וידאו הרקע (הפס בראש הדף)

בלשונית "מדיה ווידאו רקע" — מדביקים קישור CDN או מעלים קובץ, ולוחצים "שמור מדיה".

6
לפרסם — הכי חשוב

כל עוד לא לחצת "פרסם", השינויים שמורים רק בדפדפן שלך ולא באתר. לוחצים "↑ פרסם לאתר" למעלה ← מופיע "✓ פורסם" ← האתר החי מתעדכן תוך כדקה.

★
וידאו באיכות מקסימלית (לעתיד)

כשתצלם באיכות גבוהה: פותחים חשבון בשירות וידאו (Cloudflare Stream / Bunny), מעלים לשם, מעתיקים את קישור ה-HLS ומדביקים בשדה הוידאו. האתר מנגן את זה אוטומטית באיכות שמתאימה לכל מכשיר.
